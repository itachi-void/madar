# MADAR ARCHITECTURE MASTER RULE (PERMANENT & UNBREAKABLE)

## القاعدة الذهبية للمشروع (إلزامية ودائمة في madar-copy)

**«ووردبريس و WooCommerce في الخلف، و React في الواجهة الأمامية»**

### 1. دور WordPress + WooCommerce (الباك إند / Back Office):
- إدارة المنتجات (الأسماء، التوصيفات، التنويعات، الأسعار، المخزون، جداول المقاسات).
- معالجة الطلبات وإدارتها بالكامل (Orders Lifecycle).
- بوابات الدفع (الدفع عند الاستلام COD وبوابات الدفع الإلكتروني المعتمدة).
- إعدادات الشحن، ومناطق الشحن، وحساب التكاليف.
- الضرائب والعملات (الجنيه المصري EGP والريال السعودي SAR).
- إدارة العملاء والحسابات وإرسال رسائل البريد الإلكتروني.
- توفير واجهات برمجة التطبيقات:
  - `madar/v1`: للكتالوج، الإطلالات (Looks)، الخامات (Materials)، الخزانة (Wardrobe)، وخدمة المساعد (Concierge).
  - `wc/store/v1` (WooCommerce Store API): للسلة (Cart) وإتمام الطلب (Checkout) الآمن دون تسريب مفاتيح API للمتصفح.

### 2. دور React (الواجهة الأمامية / Storefront):
- الواجهة التي تم بناؤها (React + Vite + Tailwind CSS) تظل هي واجهة المتجر الحصرية والوحيدة للعملاء.
- تضم الـ Landing Page الفاخرة، والهيرو (Hero)، وتدوير الأطقم (استوديو المدار / Orbit)، ومكتبة الخامات، وتجربة القياس، والكتالوج، والسلة، والدفع.
- تجلب بياناتها وتتفاعل حصرياً ومباشرة مع WooCommerce عبر الـ REST API.
- تدعم اللغات والأسواق المستهدفة (مصر، السعودية، إلخ).

### 3. القيود والممنوعات:
- يمنع منعاً باتاً تحويل واجهة المتجر إلى قالب ووردبريس تقليدي (PHP Monolithic Theme).
- يمنع إلغاء ووردبريس أو استبدال WooCommerce بنظام تجارة إلكترونية آخر.
- يمنع إدخال بيانات متجر ثابتة (Hardcoded) في الواجهة بدلاً من جلبها ديناميكياً من WooCommerce.
